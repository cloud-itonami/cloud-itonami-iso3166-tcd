# Operator guide — TCD

Portal: armp-tchad.com -- the Autorité de Régulation des Marchés
Publics (ARMP)'s own official site (procurement notices, appels
d'offres, réglementation, plans de passation). Dossiers are first
transmitted to the Direction Générale de Contrôle des Marchés Publics
(DGCMP, a priori control, 21-day review window) before referral to
ARMP for award-stage deliberation and dispute resolution (Comité de
Règlement des Différends). Entity: RCCM (OHADA AUDCG) + DGI quitus
fiscal + the Art.128(4) evidence set (non-faillite, domiciliation
bancaire, caution de soumission, ARMP non-exclusion certificate,
CNPS). Preference-claiming engagements also clear the Code's own
Art.80 (préférence nationale, 15% ceiling) or Art.81 (préférence
genre, 10% ceiling) eligibility gate -- exactly one regime per
engagement, never both, before a filing can proceed. Human-gated
filing only.
